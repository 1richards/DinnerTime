<interfaces>
Standard pattern for this plan:
```typescript
import { getClientFor } from '../ai/clientFactory.js';
import type { StructuredTool, JsonSchema } from '../ai/types.js';

const tool: StructuredTool<OutputShape> = { name: '...', description: '...', schema: { ... } };
const ai = getClientFor('suggestions.dinner'); // or mealPlanner.week, recipe.discovery, progression.ambition, progression.variations, shoppingList.variations
const result = await ai.generateStructured({ user: promptText, tool, maxTokens: 4096 });
```

**Schema note:** Gemini requires strict JsonSchema — replace any `type: ['X', 'null']` union in existing tool schemas with a plain `type: 'X'` and omit from `required`. The tool output will return `undefined` for missing fields; existing toolOutput-to-domain conversion code already handles this via `?? null`.

**progression.ts DI removal:** Current code defines `AnthropicLike` and each AI function takes an `anthropic: AnthropicLike` parameter. Remove that parameter, remove `AnthropicLike`, and call `getClientFor('progression.ambition'|'progression.variations')` inline. Update every caller in routes/ if needed — most likely routes/progression.ts or similar.
</interfaces>
