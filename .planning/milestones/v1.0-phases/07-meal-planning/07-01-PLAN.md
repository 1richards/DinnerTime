<task type="auto">
  <name>Task 1: Create 00006_meal_plans.sql migration</name>
  <files>supabase/migrations/00006_meal_plans.sql</files>
  <action>
    Create migration defining two tables (exactly as specified in 07-RESEARCH.md Pattern 3):

    1. `meal_plans` table:
       - id UUID PK default gen_random_uuid()
       - profile_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE
       - week_start DATE NOT NULL  -- Monday of the week
       - generated_at TIMESTAMPTZ DEFAULT NOW()
       - created_at, updated_at TIMESTAMPTZ DEFAULT NOW()
       - UNIQUE(profile_id, week_start)

    2. `meal_plan_entries` table:
       - id UUID PK default gen_random_uuid()
       - meal_plan_id UUID NOT NULL REFERENCES meal_plans(id) ON DELETE CASCADE
       - day_of_week SMALLINT NOT NULL CHECK (day_of_week BETWEEN 0 AND 6)  -- 0 = Monday
       - recipe_id UUID REFERENCES recipes(id) ON DELETE SET NULL (nullable for ad-hoc AI meals)
       - title TEXT NOT NULL
       - description TEXT
       - ingredients JSONB NOT NULL DEFAULT '[]'  -- [{name, quantity, unit}]
       - ingredients_needed JSONB NOT NULL DEFAULT '[]'  -- for Phase 8 shopping
       - estimated_time_minutes INTEGER
       - difficulty TEXT CHECK (difficulty IN ('easy','medium','hard'))
       - kid_friendly BOOLEAN DEFAULT FALSE
       - why_suggested TEXT
       - status TEXT NOT NULL DEFAULT 'planned' CHECK (status IN ('planned','cooked','skipped'))
       - cooked_at TIMESTAMPTZ
       - created_at TIMESTAMPTZ DEFAULT NOW()
       - UNIQUE(meal_plan_id, day_of_week)

    Indexes:
       - idx_meal_plans_profile_week ON meal_plans(profile_id, week_start DESC)
       - idx_meal_plan_entries_plan ON meal_plan_entries(meal_plan_id)
       - idx_meal_plan_entries_cooked ON meal_plan_entries(meal_plan_id, status, cooked_at DESC)

    RLS policies (mirror 00004_recipes.sql):
       - Enable RLS on both tables
       - meal_plans: SELECT/INSERT/UPDATE/DELETE where profile_id = auth.uid()
       - meal_plan_entries: all 4 ops joined through meal_plan_id -> meal_plans.profile_id = auth.uid() (use EXISTS subquery pattern)

    Triggers:
       - meal_plans updated_at trigger using public.update_updated_at()

    Do NOT use upsert helpers here. Do NOT create meal_plans.status -- status lives on entries only.
