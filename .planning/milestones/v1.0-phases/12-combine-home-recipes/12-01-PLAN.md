**Structure (top-to-bottom):**
1. `SafeAreaView` wrapping everything (edges=['top','bottom']).
2. Compact header bar: animated opacity driven by the ACTIVE segment's `compactHeaderOpacity`. Text shows either `"Kitchen"` (when segment='suggestions', matching the large title greeting becomes the compact title 'Kitchen') OR `"Kitchen"` with subtitle `"{N} recipes"` (when segment='library'). Decision: always show "Kitchen" in compact; subtitle only in large title zone.
3. Action row (top-right): Settings gear Pressable (both segments). When segment='library', ALSO render SearchToggleButton, FilterButton, DiscoverButton (copy from today's recipes.tsx).
4. Segmented control (new): custom Pressable pair below the action row. Two pills: "Suggestions" and "Library". Active = bg-orange-500 + white text, inactive = bg-warmGray-100 + warmGray-700 text. Flex-1 each, rounded-lg, mx-4 mb-2 gap-2. Style-twin of pantry.tsx FILTER_TABS (per Research Pattern 2). Per D-01 (CONTEXT locked): iOS segmented control placement; use custom Pressable per D-Discretion + Research recommendation (avoids native-module dev-client rebuild).
5. **Both lists rendered in parallel**, one hidden via `display: none`:
   - `<View style={[{flex:1}, segment !== 'suggestions' && {display:'none'}]}>`: `<SuggestionList HeaderComponent={<SuggestionsHeader />} onScroll={suggestionsHeader.onScroll} />`.    - `<View style={[{flex:1}, segment !== 'library' && {display:'none'}]}>`: Full `Animated.FlatList<Recipe>` copied from recipes.tsx, using `libraryHeader.onScroll`, library large-title animated header shows `"Kitchen"` + `"{recipes.length} recipes"` subtitle (Pantry pattern). 7. `<RecipeFilterSheet>` modal — same placement as recipes.tsx, only meaningful when segment='library' but harmless to always mount.
