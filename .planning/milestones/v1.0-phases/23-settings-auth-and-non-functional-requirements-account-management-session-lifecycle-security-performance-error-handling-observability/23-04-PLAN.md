  <behavior>
    - authedFetch(path: string, init?: RequestInit): builds fullUrl = `${EXPO_PUBLIC_API_URL}${path}`. Reads current session access_token via supabase.auth.getSession(). Sets Authorization: Bearer token. Sets Content-Type: application/json if body exists and no header override. Delegates to global fetch.
    - On response 401: calls attemptSessionRefresh(). If success → retries the original request ONCE with the new access token. If retry also 401 OR refresh failed → calls triggerReAuth() (which causes ReAuthModal to show at root) and throws a 'REAUTH_REQUIRED' error. Callers catch and render inline error.
    - attemptSessionRefresh(): supabase.auth.refreshSession() → { success: boolean; accessToken?: string }. Idempotent: if a refresh is already in flight, await the existing promise (single-flight).
    - setReAuthHandler(handler) + triggerReAuth(): module-level handler registry. _layout.tsx registers a handler that flips a useState showReAuth to true; ReAuthModal renders when showReAuth.
    - ReAuthModal: Modal presentationStyle 'pageSheet', password Input, Sign-in Button. On submit: supabase.auth.signInWithPassword({ email: user.email, password }) → on success dismiss modal + clear showReAuth; on error show inline error.
    - Tests: authedFetch.test.ts 4 cases (Bearer attached, base URL prepended, 401 retry-once-success, 401 second-401-calls-triggerReAuth). sessionRefresh.test.ts 3 cases (refresh success, refresh failure returns {success:false}, single-flight de-dupe). ReAuthModal.test.ts 3 cases.
  </behavior>
