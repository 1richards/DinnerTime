Optimistic pattern for mutations (per Phase 6-03 decision):
```typescript
toggleChecked: async (id) => {
  const snapshot = get().items;
  set({ items: snapshot.map(i => i.id === id ? {...i, checked: !i.checked} : i) });
  try {
    const target = snapshot.find(i => i.id === id);
    await authedFetch(`/shopping/items/${id}`, { method: 'PATCH', body: JSON.stringify({ checked: !target!.checked }) });
  } catch (e) {
    set({ items: snapshot, error: (e as Error).message });
  }
}
```

Avoid: Do NOT skip rollback on failure. Do NOT use temp IDs that could collide (use `crypto.randomUUID()` or a monotonic counter). Do NOT fetch after every optimistic change — trust the optimistic state unless server disagrees.

```typescript
createOrder: async () => {
  const list = get().currentList;
  if (!list) throw new Error('No active shopping list');
  const res = await authedFetch(`/shopping/${list.id}/order`, { method: 'POST' });
  const data = await res.json(); // { url, order_id }
  // Optimistically append a placeholder order; refresh from server next fetchOrders call
  return data;
},

reorder: async (orderId) => {
  const res = await authedFetch(`/shopping/orders/${orderId}/reorder`, { method: 'POST' });
  const list = await res.json();
  set({ currentList: list, items: list.items });
  return list;
},

fetchVariations: async (orderId) => {
  const res = await authedFetch(`/shopping/orders/${orderId}/variations`, { method: 'POST' });
  const data = await res.json();
  set({ variations: data });
  return data;
}
```
