    - Hook signature: `useCurrentStepScroll(scrollRef: RefObject<ScrollView>, stepYs: RefObject<number[]>, currentStepIndex: number): void`.
    - useEffect on currentStepIndex change:
      - `const y = stepYs.current[currentStepIndex];`
      - If `y !== undefined && scrollRef.current`, call `scrollRef.current.scrollTo({ y: Math.max(0, y - 120), animated: true })`.
      - The `-120` offset centers the current step roughly 1/3 down the viewport — per Pattern 2 and CONTEXT "scroll animates to center the new current step".
    - Pitfall 4 guard: this hook fires on every currentStepIndex change unconditionally. If UAT surfaces user-scroll-fighting-autoscroll, add an onScrollBeginDrag/End gate in a follow-up — not shipped in this plan.
