  <name>Task 1: POST /api/v1/cooking/ask</name>
  <files>packages/server/src/routes/cooking.ts, packages/server/src/routes/__tests__/cooking.test.ts, packages/server/src/index.ts</files>
  <behavior>
    Request body: `{ recipe_id: string, current_step_index: number, question: string }`

    Happy path:
    - Auth middleware passes; userId present
    - Recipe exists for that user -> load title, steps, ingredients
    - current_step_index is clamped to [0, steps.length-1]
    - Call anthropic.messages.create with:
      - model: 'claude-sonnet-4-latest'
      - max_tokens: 200
      - system prompt includes recipe title, current step text, ingredients list, and the rule: "Answers MUST be 1-3 sentences, spoken conversationally, no markdown, no bullet lists, no preamble."
      - user message = question (verbatim)
    - Extract text from response.content[0].text
    - Truncate to 300 chars (belt-and-suspenders per Pitfall 6)
    - Return `{ answer: string }` with 200

    Error paths:
    - Missing/invalid body fields -> 400 { error: 'INVALID_REQUEST' }
    - Recipe not found or not owned by user -> 404 { error: 'RECIPE_NOT_FOUND' }
    - Anthropic call throws -> 502 { error: 'CLAUDE_ERROR' }

    Tests (cooking.test.ts) mock @anthropic-ai/sdk default export and Supabase client (reuse existing test helper if present, otherwise inline like shopping.test.ts). Cover: 200 happy path with prompt-contains assertions, 404 wrong-user, 400 missing body, 502 on Claude throw, 300-char truncation.
  </behavior>
  <action>
    1. Create packages/server/src/routes/cooking.ts. Mirror shopping.ts structure: `const cooking = new Hono(); cooking.use('*', authMiddleware); cooking.post('/ask', handler); export default cooking;`
    2. Load recipe using the existing Supabase pattern (copy from recipes.ts GET /:id). Return 404 on not found.
    3. Build system prompt per research Pattern 5 (verbatim — the "no preamble" rule is load-bearing).
    4. Use the existing Anthropic lazy singleton from `src/config/anthropic.ts` — DO NOT construct a new SDK client inline.
    5. Extract text: `res.content.find(b => b.type === 'text')?.text ?? ''`
    6. Truncate: `answer.length > 300 ? answer.slice(0, 297) + '...' : answer`
    7. Mount in packages/server/src/index.ts: `import cooking from './routes/cooking.js'; app.route('/cooking', cooking);` — add AFTER the existing `voice` route (leave voice route in place; cooking is the new sibling).

    Note: `voice.ts` transcribe stub is unrelated and stays in place. This is a separate namespace because `/voice/transcribe` is a future fallback (Whisper) — `/cooking/ask` is the Claude Q&A endpoint.

    Write cooking.test.ts FIRST (RED), implement, GREEN.
