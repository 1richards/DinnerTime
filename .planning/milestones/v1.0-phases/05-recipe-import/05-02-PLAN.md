  <implementation>
    parseRecipeFromUrl:
    1. Fetch URL with User-Agent header ("DinnerTime/1.0"). Handle 4xx/5xx with clear error.
    2. Load HTML with cheerio, find all script[type="application/ld+json"] tags.
    3. For each, try JSON.parse, recursively search for @type: "Recipe" (handle @graph arrays, nested types).
    4. If found, mapJsonLdToRecipe (map name->title, recipeIngredient->ingredients via Claude parse, recipeInstructions->steps, prepTime/cookTime via parseDuration, recipeYield->servings, image->image_url).
    5. Note: JSON-LD recipeIngredient is string[] ("2 cups flour"), so still send through Claude parse_recipe tool for structured ingredient parsing.
    6. If no JSON-LD found, extract visible text with cheerio (strip scripts/styles), send to Claude with parse_recipe tool.

    parseRecipeFromPhoto:
    - Follow vision.ts identifyFoodItems pattern exactly. Send base64 image with recipe extraction prompt. Use parse_recipe tool with forced tool_choice. Extract result from tool_use content block.

    parseRecipeFromText:
    - Send freeform text to Claude with parse_recipe tool and forced tool_choice. Prompt: "Parse this recipe text into structured format. Convert fractions to decimals for quantities."

    recipeStore.ts:
    - saveRecipe: insert into recipes table with profile_id, return the created row.
    - getRecipes: select from recipes where profile_id, order by created_at desc.
    - getRecipeById: select single recipe by id and profile_id.

    recipes.ts routes (expand existing stub):
    - POST /import/url: validate body has url string, call parseRecipeFromUrl, return { data: parsedRecipe }.
    - POST /import/photo: validate body has image (base64 string), call parseRecipeFromPhoto, return { data: parsedRecipe }.
    - POST /import/text: validate body has text string, call parseRecipeFromText, return { data: parsedRecipe }.
    - POST /: validate body matches ParsedRecipe shape, call saveRecipe with user's profile_id from auth context, return { data: savedRecipe }.
    - GET /: call getRecipes with profile_id, return { data: recipes }.
    - Duplicate check on POST /import/url: check if source_url already exists, return { data: existingRecipe, duplicate: true } if found.
  </implementation>
</feature>
