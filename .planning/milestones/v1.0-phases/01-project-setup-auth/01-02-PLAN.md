  <behavior>
    - LargeSecureStore.setItem encrypts a value and stores it; getItem decrypts and returns it
    - LargeSecureStore.removeItem clears both SecureStore key and AsyncStorage value
    - Auth store initializes with isLoading=true, isLoggedIn=false, session=null
    - Auth store sets isLoggedIn=true when session is received via onAuthStateChange
    - Auth store sets isOnboarded based on profile.onboarding_complete from Supabase
    - Auth store resets to logged-out state when session becomes null
  </behavior>
  <action>
    1. Create `src/lib/supabase.ts`:
       - Implement LargeSecureStore class exactly per the research pattern: AES-256 encryption key in expo-secure-store, encrypted session data in AsyncStorage. Import react-native-get-random-values at the top of the file (MUST be before any crypto usage).
       - Export `supabase` client created with createClient() using EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY, configured with storage: new LargeSecureStore(), autoRefreshToken: true, persistSession: true, detectSessionInUrl: false.

    2. Create `src/stores/authStore.ts`:
       - Zustand store with state: session, user, isLoggedIn, isOnboarded, isLoading, profile (display_name, household_size, etc.)
       - `initialize()` method: calls supabase.auth.onAuthStateChange, on session change updates state. When session exists, fetches profile from profiles table to check onboarding_complete. Returns cleanup function (subscription.unsubscribe).
       - `signOut()` method: calls supabase.auth.signOut(), resets state
       - Use the pattern from RESEARCH.md Pattern 3

    3. Create `src/hooks/useAuth.ts`:
       - Export hook with convenience methods: signInWithEmail(email, password), signUpWithEmail(email, password), signInWithApple(), signInWithGoogle(), signOut()
       - signInWithApple(): uses expo-apple-authentication, exchanges credential.identityToken via supabase.auth.signInWithIdToken. CRITICAL: capture credential.fullName on first sign-in and save to user metadata immediately (Apple only provides this once).
       - signInWithGoogle(): uses @react-native-google-signin/google-signin, exchanges idToken via signInWithIdToken. Configure with webClientId from env.
       - All methods return { data, error } pattern for consistent error handling

    4. Create `src/components/ui/Button.tsx` and `src/components/ui/Input.tsx`:
       - Button: Pressable with NativeWind styling, supports variant (primary with warm orange bg, outline, ghost), loading state with ActivityIndicator, disabled state
       - Input: TextInput with label, error message display, NativeWind styling, supports secureTextEntry for passwords
       - Use warm color palette: primary orange/amber (#F97316 or similar), warm grays for text, cream/warm white backgrounds

    5. Write tests in `__tests__/auth-store.test.ts`:
       - Test auth store state transitions (mock supabase module). Verify initial state, verify state after session received, verify state after sign out.
  </action>
