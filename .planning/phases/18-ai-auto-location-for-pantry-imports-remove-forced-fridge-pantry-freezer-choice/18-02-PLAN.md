<objective>
Wire the backend to use per-item location: extend every vision tool schema with `source_location`, apply STATIC_MAP correction post-AI in vision.ts, make `reconcileItems` dual-write to both `source_location` column and `item_attributes.source_location`, strip `source_location` body params from every scan route, make `/confirm` use per-item location, and add the new `POST /api/v1/pantry/override-events` route for telemetry.

Purpose: This is the "classifier is live across all four flows" wave. After this wave, a single photo or receipt scan produces items with per-item locations; a receipt with milk+chips+ice-cream naturally fan-outs across fridge/pantry/freezer (ROADMAP Success Criterion #5). The dual-write is the forward-compat bridge for Phase 24.

Output: Extended tool schemas, corrected-by-STATIC_MAP return path, modified reconcileItems, stripped route validation, new override-events route. All backed by extensions to existing server test files.
</objective>
