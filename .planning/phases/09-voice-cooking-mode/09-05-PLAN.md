    **cook.tsx** — full implementation per 09-RESEARCH.md "Dispatch loop tying it together":
    1. `useKeepAwake()` at the top of the component body (Pitfall 5 — hook, not imperative)
    2. `<Stack.Screen options={{ headerShown: false, gestureEnabled: false }} />` to prevent accidental swipe-back while cooking
    3. Read recipe id from `useLocalSearchParams<{ id: string }>`. Load the recipe from recipeStore (it's already cached from the detail screen) — if somehow missing, call a lightweight recipeStore fetch or show error. On mount call `store.enter(recipe)`; on unmount call `store.exit()` + `Speech.stop()`.
    4. `useStepSpeaker(recipe.steps[stepIndex], ttsEnabled)` — auto-reads each step
    5. `useVoiceListener(handleTranscript, voiceEnabled, contextualStrings)` where contextualStrings = `['next step','go back','repeat','timer','pause', ...recipe.ingredients.map(i => i.name)]`
    6. `handleTranscript` dispatcher per research pattern — for `ask` intents, `setLoading(true)`, await `askAssistant`, store answer via `store.setAssistantAnswer`, then TTS-speak the answer. Always `Speech.stop()` before next/back/repeat.
    7. Render: VoiceStatusBadge (top-right) + StepDisplay (main) + TimerBar (above nav) + StepNavButtons (bottom) + AskSheet (overlay when answer present)
    8. A `useEffect` with `setInterval(1000)` that ticks `remainingMs` on active timers and calls `removeTimer` when one reaches 0 (also Speech.speak the timer-done announcement).
    9. Exit button in top-left that `router.back()` and also calls store.exit() — the unmount hook should too, but be explicit.

    **recipe detail [id]/index.tsx** — add a primary "Start Cooking" button (large, brand-coloured) above or below the ingredients block. On press: `router.push(\`/recipes/${id}/cook\`)`. Keep existing layout intact.

    **(tabs)/cook.tsx** — the existing placeholder is now misleading because cooking happens per-recipe. Replace its body with a helpful empty state: "Pick a recipe from your library and tap Start Cooking". Link-button back to /recipes tab. Keep the file (removing it would require updating _layout.tsx which is out of scope).

    **cook.test.tsx** — integration test using the module mocks from 09-04 Task 1. Test matrix:
    - Mounts with a mock recipe injected into cookingStore via setState -> Step 1 renders text
    - useKeepAwake was called (`expect(useKeepAwake).toHaveBeenCalled()`)
    - Tapping Next button -> cookingStore.stepIndex advances to 1 (query via getState)
    - Simulating a final 'next' transcript via calling the handleTranscript exposed either through a test-only ref OR by firing `useSpeechRecognitionEvent`'s registered callback (mock captures the callback) -> stepIndex advances
    - Simulating transcript 'set a timer for 10 minutes' -> timers array has 1 entry, label contains '10 min'
    - Unmount -> Speech.stop mock called

    Note: if testing the voice dispatch through the real event subscription is too brittle, factor `handleTranscript` into a module-level pure function that the test imports directly. Document whichever approach you take in the summary.
