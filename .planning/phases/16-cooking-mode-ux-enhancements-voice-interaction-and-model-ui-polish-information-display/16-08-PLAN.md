    §Haptics (COOK-UX-05):
    - Voice-next → confirm medium buzz on recognized intent.
    - Tap ingredient → confirm light buzz.
    - Let a timer hit T-10s → confirm light buzz.
    - Let a timer expire → confirm success-notification buzz + TTS announcement.
    - Tap Exit → End cooking session → confirm warning buzz.
    - Tap Stop TTS while Claude is speaking → confirm medium buzz + TTS halts.

    §TTS Audibility (COOK-UX-01):
    - Cook at counter arm's length — TTS clearly audible.
    - AirPods connected — TTS routes to AirPods cleanly.
    - Plug into CarPlay-style wired audio if available — TTS routes correctly.
    - Note any issues (Pitfall 3: if TTS sounds "phone-call volume" when STT is active, document — may escalate to Phase 23).

    §Dark Mode (COOK-UX-03):
    - Settings → Cooking → Dark cooking mode → ON.
    - Cook a recipe. Evaluate on OLED:
      - No grey-crush in dark areas
      - Current-step card readably distinct from non-current
      - Brand accent color still reads as terracotta (not washed out)
      - Step transitions smooth (no flash)
    - Document any issues.

    §Real-Kitchen Session (COOK-UX-02):
    - Cook one full recipe end-to-end in a real kitchen (sizzle, vent hood, background talk).
    - Use voice commands throughout.
    - Count STT misrecognitions. Count AskSheet fall-throughs (unrecognized commands that became questions).
    - After cooking, query Supabase: `select event_type, count(*) from cooking_events where session_id = '<your-session>' group by event_type`.
    - Verify events present: stt_final, intent_routed, ask_start, ask_first_chunk, ask_complete, tts_echo_swallowed (if any).
    - Verify NO raw transcript text in payload column.
