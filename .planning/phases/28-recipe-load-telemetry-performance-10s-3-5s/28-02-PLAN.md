<objective>
Time POST /generate-image into ai_events (T2), stop the Recipe Box list from ever generating on the critical path by generating image_url at SAVE time fire-and-forget (O2), and provide a manual idempotent backfill for legacy null-image_url rows (O3).

Purpose: O2+O3 are the dominant fix — once every recipe row has image_url populated before the list loads, the image hook's `skip:true` branch fires and ZERO generate-image requests happen on a cold open. T2 quantifies the per-image Gemini cost so the deploy-measure step can prove the win.
Output: generateRecipeImage exposes hit/miss + latency; /generate-image records to ai_events; POST / generates-on-save fire-and-forget; new POST /backfill-images route + tests.
</objective>
