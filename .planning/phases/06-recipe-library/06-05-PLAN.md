    - Multiplier: `(recipe?.servings ?? 1) &gt; 0 ? servings / (recipe.servings ?? 1) : 1`.
    - Render: Title, `FavoriteButton`, `ServingSizeStepper`, `ScaledIngredientList`, numbered steps list, Edit button (`router.push(\`/recipes/${id}/edit\`)`), Delete button (Alert.alert confirmation -&gt; `deleteRecipe(id)` -&gt; `router.back()`).

    - On Cancel: `router.back()`.
