    - updateReviewItem(id, updates): modifies a ReviewItem in scanResults (change name, quantity, toggle accepted)
    - addReviewItem(item): adds a manually-created ReviewItem to scanResults
    - removeReviewItem(id): removes a ReviewItem from scanResults
    - confirmScan(profileId, sourceLocation): sends accepted ReviewItems to POST /api/v1/pantry/confirm, merges result into items
    - markItemUsed(itemId): optimistically sets status='used', calls PATCH /api/v1/pantry/:id, rollback on error
    - markItemDepleted(itemId): optimistically sets status='depleted', calls PATCH /api/v1/pantry/:id, rollback on error
  </behavior>
  <implementation>
    Follow existing preferencesStore.ts pattern. Mock supabase in tests. Mock fetch for backend API calls. 
    Store state: { items: PantryItem[], scanResults: ReviewItem[], isScanning: boolean, isLoading: boolean }.
    API calls to backend use the authenticated user's token from supabase.auth.getSession().
  </implementation>
