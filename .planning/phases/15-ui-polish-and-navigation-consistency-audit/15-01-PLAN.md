    Create three bash scripts that Wave 3 will wire into the phase gate. Each MUST exit non-zero on violation (no `|| echo` masking patterns — downstream quality gate depends on genuine failure propagation).

    **verify-no-ionicons.sh:**
    ```bash
    #!/usr/bin/env bash
    set -euo pipefail
    # Fails if any file under apps/mobile/src imports from @expo/vector-icons.
    # Phase 15 mandate: SF Symbols via expo-symbols is the only icon family.
    ROOT="$(cd "$(dirname "$0")/.." && pwd)"
    MATCHES=$(grep -rn "from '@expo/vector-icons'" "$ROOT/src" || true)
    if [[ -n "$MATCHES" ]]; then
      echo "FAIL: Ionicons imports still present:"
      echo "$MATCHES"
      exit 1
    fi
    echo "OK: no Ionicons imports under apps/mobile/src"
    ```

    **verify-no-decorative-emoji.sh:**
    ```bash
    #!/usr/bin/env bash
    set -euo pipefail
    # Fails if decorative emoji unicode (U+1F300-U+1F9FF) appears inside
    # <Text> nodes under apps/mobile/src/app. Components/leaf files are out
    # of scope (e.g., RecipeFilterSheet emojis defer to Phase 19 chip rewrite).
    ROOT="$(cd "$(dirname "$0")/.." && pwd)"
    # ripgrep is not guaranteed; use grep -P for PCRE unicode range.
    MATCHES=$(grep -rnP "[\x{1F300}-\x{1F9FF}]" "$ROOT/src/app" || true)
    if [[ -n "$MATCHES" ]]; then
      echo "FAIL: decorative emoji detected in app routes:"
      echo "$MATCHES"
      exit 1
    fi
    echo "OK: no decorative emoji under apps/mobile/src/app"
    ```
    NOTE: Mac grep on Darwin 25.2 supports `-P` via the default BSD grep in newer releases; if runtime testing shows -P is unavailable, fall back to perl one-liner: `perl -ne 'print "$ARGV:$.:$_" if /[\x{1F300}-\x{1F9FF}]/' $(find "$ROOT/src/app" -type f \( -name '*.ts' -o -name '*.tsx' \))`. Pick whichever works on the current host; test the script locally before committing.

    **verify-headers.sh:**
    ```bash
    #!/usr/bin/env bash
    set -euo pipefail
    # Counts hand-rolled back-button Pressables under apps/mobile/src/app.
    # Known-legitimate exception: recipes/[id]/index.tsx floating back over hero image.
    # Exit non-zero if count exceeds the expected exception budget.
    ROOT="$(cd "$(dirname "$0")/.." && pwd)"
    EXPECTED_MAX=1
    COUNT=$(grep -rn "onPress.*router\.back" "$ROOT/src/app" | grep -c "Pressable\|TouchableOpacity" || true)

      echo "FAIL: $COUNT hand-rolled back Pressables found; expected <= $EXPECTED_MAX (recipes/[id]/index hero)"
      exit 1
    fi
    echo "OK: $COUNT / $EXPECTED_MAX hand-rolled back Pressables (within budget)"
    ```
