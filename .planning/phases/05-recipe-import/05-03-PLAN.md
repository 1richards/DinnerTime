  <behavior>
    - importFromUrl(url): sets isImporting=true, POSTs to /import/url, stores result in importedRecipe, handles duplicate flag, sets isImporting=false
    - importFromPhoto(base64): sets isImporting=true, POSTs to /import/photo, stores result in importedRecipe, sets isImporting=false
    - importFromText(text): sets isImporting=true, POSTs to /import/text, stores result in importedRecipe, sets isImporting=false
    - saveRecipe(recipe): POSTs ParsedRecipe to /recipes, adds returned Recipe to recipes array, clears importedRecipe
    - fetchRecipes(): GETs /recipes, sets recipes array
    - clearImport(): clears importedRecipe and error state
    - Error handling: all actions set error string on failure, clear on success
    - Duplicate detection: importFromUrl sets isDuplicate=true and existingRecipe when server returns duplicate flag
  </behavior>
  <action>

- Local getApiBaseUrl() and getAuthToken() helpers (same code as suggestionsStore)

- Error handling: try/catch with error state (no throwing), same pattern as suggestionsStore.fetchSuggestions
- Import actions store the parsed recipe in importedRecipe for user review
- saveRecipe sends the reviewed (possibly edited) ParsedRecipe to POST /recipes, then prepends the saved Recipe to the recipes list
